# Лендинги стабилизаторов напряжения — oasis.com.ru

Пять посадочных страниц под Яндекс Директ (Симферополь, Крым) и главная страница. Продаются стабилизаторы
Exegate и Ресанта. Сайт статический: HTML собирается Python-скриптами, форма заявок — один PHP-файл.

**Сайт:** https://oasis.com.ru/

| Адрес | Запрос в Директе | Что за механика на странице |
|---|---|---|
| `/` | главная | WebGL-шейдер «полёт сквозь огни», карточки с бегущей рамкой, «гармошка» из 6 моделей |
| `/resanta/` | стабилизатор Ресанта | калькулятор нагрузки → подбор СПН-3600 / СПН-13500 |
| `/10kvt/` | стабилизатор для дома 10 кВт | шкала напряжения сети → какая модель подходит и сколько мощности доступно |
| `/spn-13500/` | Ресанта СПН-13500 | осциллограф «сеть → ровные 220 В» + разбор прибора по ракурсам |
| `/exegate/` | Exegate для дома | вкладки моделей + фотореалистичный дом с крупным стабилизатором |
| `/exegate-15kvt/` | Exegate 15 кВт | метки на крупном фото (дисплей, автомат, байпас, клеммы) |
| `/privacy/` | — | политика конфиденциальности (152-ФЗ) |

## Быстрый старт

```bash
pip install -r requirements.txt
python make_all.py          # собирает site/ (и dist/oasis-site.zip)
python -m http.server 8791 --directory site   # посмотреть локально: http://localhost:8791
```

Выкладка на хостинг (SFTP) — см. [docs/DEPLOY.md](docs/DEPLOY.md). Пароли в репозитории не хранятся.

## Что в репозитории

```
make_all.py        единая сборка сайта: страницы, неразрывные пробелы в ценах, правила для мобильных
build.py           общие данные (контакты, ИП, шаги, FAQ), политика, sitemap, robots, список страниц
build_home.py      главная: шейдер, карточки, «гармошка» моделей
build_beacon.py    /10kvt/  — стиль «луч света» + шкала напряжения
build_cinnabar.py  /resanta/ — стиль «багровый дым» + калькулятор
build_zephyr.py    /exegate/ — стиль «шалфей» + вкладки моделей + дом
build_wow.py       /spn-13500/ и /exegate-15kvt/ — тёмный «техно» стиль, общий каркас и JS
widgets.py         интерактивные блоки: метки, шкала напряжения, калькулятор, вкладки моделей
fx.py              интерактивные фото: наклон, свечение, увеличение, карусель «по полочкам»
catalog.py         проверенные данные моделей, список «что на складе», цены, подготовка фото
cutout.py          простое вырезание товара с белого фона (алгоритмическое)
house_matte.py     качественное вырезание дома с листвой (альфа-матирование)
server/            send.php (приём заявок → Telegram/почта), config.sample.php, .htaccess
site/              готовый сайт (то, что лежит на хостинге), site/img — оптимизированные фото
docs/              документация проекта (см. ниже)
```

## Важно знать

- **Цены и список моделей** задаёт владелец: `catalog.py → STOCK` (6 моделей). Остальные модели Exegate/Ресанта на сайте отключены.
- **Характеристики** берутся с сайтов производителей (exegate.com, resanta.ru), а не из интернет-магазинов.
- **Фото товаров** принадлежат производителям Exegate и Ресанта. Репозиторий публичный — если вы не официальный дилер, держите его закрытым.
- **Секреты** (токен Telegram-бота, ID чата, пароль хостинга) в репозиторий не попадают: `config.php` создаётся на сервере, пароль SFTP передаётся переменными окружения.
