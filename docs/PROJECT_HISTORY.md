# История проекта

Хронология работы от идеи до выкладки. Даты — 2026-10-04…07.

## 1. Задача
Владелец продаёт стабилизаторы напряжения в Симферополе и запускает рекламу в Яндекс Директ с локальным таргетом.
Нужно пять лендингов — по одному под каждый поисковый запрос:

1. Стабилизатор Ресанта
2. Стабилизатор для дома 10 кВт
3. Ресанта СПН-13500
4. Стабилизатор Exegate для дома
5. Стабилизатор Exegate 15 кВт

Требования: просто, красиво, лаконично; на каждой странице свой стиль, чтобы выбрать лучшее и при необходимости переверстать;
домен `oasis.com.ru`; доставка по Крыму и на новые территории транспортными компаниями; установку не делаем;
работаем с 7:00 до 22:00; телефон +7 978 579-29-95; заявки в Telegram.

## 2. Как шла работа

### Этап 1. Проектирование (04.10)
- Через процесс brainstorming согласовали цель, структуру страницы (заголовок под запрос → преимущества → характеристики →
  как заказать → доставка → FAQ → заявка), цели Метрики и пять стилей. Спецификация и план: `docs/superpowers/`.
- Решение: статический сайт, один самодостаточный `index.html` на страницу, без фреймворков и сборщиков — быстро грузится, легко залить на любой хостинг.
- Данные для текстов собраны из открытых источников; цены владелец не давал, поэтому сначала стояло «уточняйте по телефону».

### Этап 2. Первая версия и публикация (04–05.10)
- `build.py` — генератор: шаблон + контент + пять тем оформления (светлый, тёплый, тёмный технический, журнальный, яркий).
- Форма заявки `server/send.php` → Telegram. Политика конфиденциальности по реквизитам ИП. Метрика (цели `call`, `tg`, `form`).
- Выкладка на Sprinthost. Обнаружили, что FTP отвечает ложными ошибками `451`, — перешли на SFTP/SSH (paramiko).
- Нашли, что у домена нет A-записи (только IPv6), — владелец добавил A-запись `141.8.192.36`.
- Часть «сбоев» сайта оказалась локальным прокси на компьютере разработчика: все проверки с этого момента идут с `curl --noproxy '*'`.

### Этап 3. «Вау»-страницы со scroll-анимацией (05–06.10)
- Владелец показал референсы — шаблоны с scrolltide.co (Beacon, Cinnabar, Coffee, Zephyr) и попросил «нечто нереальное».
  Шаблоны платные, код закрыт, поэтому **ничего не копировалось**: страницы написаны с нуля по скриншотам и описаниям (см. `SOURCES.md`).
- Сделано пять стилей: осциллограф (СПН-13500), Beacon (10 кВт), Cinnabar (Ресанта), Zephyr (Exegate), техно (15 кВт).
- Beacon пришлось переделывать по скриншотам оригинала: медный, а не жёлтый луч; лёгкий шрифт; стеклянные плашки.
- Zephyr переделан с «домашнего» стиля на стиль шаблона Zephyr; затем шрифт заменён с «литературного» Playfair на геометрический Manrope.

### Этап 4. Реальные данные и фото (06.10)
- Владелец дал ссылки на каталоги производителей. Собраны официальные характеристики и фото **10 моделей Exegate** (серии AS, AV, AVS, AST, XV) и **8 моделей Ресанта СПН**.
- Исправлены ошибки, взятые из интернет-магазинов: время переключения «менее 7 мс» (не 5–7), ток 15-киловаттных моделей 75 А (не 80),
  AST-15000 — 15 кВт (не 9), «цветной дисплей» убран (у производителя просто LCD).
- Товары вырезаны с белого фона: сначала алгоритмом (`cutout.py`) — не справился с белым корпусом на белом; затем нейросетью rembg (u2net).
- Фото сделали интерактивными: наклон за курсором, свечение, увеличение по клику (`fx.py`).

### Этап 5. Одинаковая карусель не подошла (06.10)
- Прокрутка с исчезающими приборами на всех страницах — «не круто». Оставили только на `/spn-13500/`.
- Остальным подобраны **разные механики** под задачу страницы (`widgets.py`): калькулятор нагрузки, шкала напряжения, вкладки моделей, метки на фото.

### Этап 6. Реалистичный дом (06.10)
- Первый дом, собранный из кубиков на three.js, отвергнут: «рисунок в пейнте». 3D-программ на компьютере не было.
- Дом сгенерирован нейросетью (Canva, затем картинки владельца), вырезан с белого фона. Для листвы написано отдельное
  альфа-матирование (`house_matte.py`): вычитание белого фона из полупрозрачных пикселей кроны, защита воды и плит от чистки.
- Подготовлен промпт для генерации дома на белом фоне под вырезание.

### Этап 7. Склад и цены (06–07.10)
- Владелец прислал список того, что приедет на склад: 4 модели Exegate (AST-500, AST-2000, AVS-2000, AST-15000) и 2 Ресанта (СПН-3600, СПН-13500) с ценами.
  Все остальные модели отключены (`catalog.py → STOCK`). Страницы перестроены под эти шесть моделей.
- Подставлены Telegram (`https://t.me/B2B_opt_simf`) и счётчик Метрики 113489938.
- Уведомление в Telegram переделано в карточку: эмодзи, цитата, хэштеги, кнопки (MAX, Telegram, страница), метки рекламы `utm`/`yclid`.

### Этап 8. Главная и доводка (07.10)
- Новая главная по референсам UIverse и 21st.dev (ATC Shader): свой WebGL-шейдер, карточки с бегущей рамкой.
- Ряд моделей с тонкой полосой прокрутки заменён «гармошкой»: наведение раскрывает панель, плюс автоперелистывание.
  Цены в свёрнутых панелях — крупные оранжевые.
- Мобильная версия: шейдер переведён на расчёт по ширине экрана, всё центрировано, кнопки одной ширины.
- Аудит: проверка всех страниц на ширинах 320–414 и 1280–1920 px на выход за экран и перекрытия фото с текстом.

## 3. Ошибки, из которых вынесли уроки
| Проблема | Причина | Решение |
|---|---|---|
| Фото растягивалось и закрывало текст (карточки, калькулятор, «по полочкам», главная) | высота в процентах у дочернего элемента grid | фиксированная высота или `max-height` в `px`/`vh` |
| Обрезанная справа шапка с номером на телефоне | логотип + номер не помещаются | на узких экранах скрываем «· Симферополь», `white-space:nowrap` |
| Цена рвалась «28 / 990 ₽»; цифры превратились в квадраты | не было неразрывных пробелов; ошибка в регулярке (`\1` без raw-строки) | функция `nbsp()` в `make_all.py`, проверка на управляющие символы |
| Белая кайма на листве вырезанного дома | цвета листьев на краю смешаны с белым фоном | обратное смешивание: F = (C − 255·(1−α)) / α |
| Шейдер на телефоне почти не виден | поле считалось по высоте, на портрете узкая полоска | масштаб по `min(R.y, R.x·0.56)` + автодвижение камеры без мыши |
| Мои проверки «видели» старую версию | кэш браузера | `?v=<timestamp>` в проверках, `Cache-Control: max-age=0` для HTML на сервере |
| FTP отвечал `451`, сайт «не открывался» | локальный прокси и особенности FTP-сервера | SFTP + `curl --noproxy '*'` |
