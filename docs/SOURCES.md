# Источники: данные, фото, идеи и референсы

## 1. Данные о товарах
| Что | Откуда |
|---|---|
| Характеристики Exegate (AS, AV, AVS, AST, XV; мощность, вход, ток, габариты, вес, байпас) | карточки моделей на https://www.exegate.com/catalogue/stabilizer/ |
| Характеристики Ресанта СПН (0,9–22,5 кВт; полные данные СПН-13500) | https://resanta.ru/category/stabilizatory-napryazheniya/filter/ponizhennogo-napryazheniya/ |

Правило: цифры берём только у производителя. Данные из интернет-магазинов оказались неточными (см. `PROJECT_HISTORY.md`).
У трёх маленьких Exegate (AST-500, AST-2000, AVS-2000) производитель указывает только ВА, — в кВт не пересчитываем.

## 2. Фото
- **Фото моделей** скачаны с exegate.com и resanta.ru (папка `assets/`, в репозиторий не входит), вырезаны с фона и сжаты в `site/img/*.webp`.
  Права на фото принадлежат производителям. Использование на сайте — по решению владельца (дилер).
- **Дом (первый экран `/exegate/`)** — изображение, сгенерированное нейросетью (Canva, затем картинки владельца), вырезано `house_matte.py`.
  Это визуализация, а не фото реального объекта.
- Для вырезания использована модель **u2net** из библиотеки [rembg](https://github.com/danielgatis/rembg) (MIT). Модель скачивается при первом запуске.

## 3. Референсы дизайна (идеи, не код)
Платные шаблоны **scrolltide.co** (https://www.scrolltide.co/templates): код закрыт подпиской, виден только демо-ролик и описание.
**Ничего оттуда не копировалось** — ни код, ни картинки, ни видео. Страницы написаны с нуля по скриншотам и описаниям,
которые присылал владелец. Идеи заимствованы на уровне «настроения»:

| Наша страница | Референс | Что взяли как идею | Что сделано своё |
|---|---|---|---|
| `/10kvt/` (Beacon) | шаблон Beacon | тёмный фон, медный столб света из тонких лучиков, плашки вокруг заголовка, горизонт из светящихся волн, лососёвые акценты | собственный canvas-шейдер, шкала напряжения |
| `/resanta/` (Cinnabar) | шаблон Cinnabar | багровый дым, световые следы, красные ключевые слова в заголовке, две большие карточки, «пилюля»-меню | собственный canvas, калькулятор нагрузки |
| `/exegate/` (Zephyr) | шаблон Zephyr | шалфейная дымка, Playfair+DM Sans (затем заменён на Manrope), «рейка» из 4 шагов | вкладки моделей, дом, свой SVG-рисунок рейки |
| `/exegate/` — первая версия «Coffee» (отвергнута) | шаблон Coffee | тёплый неторопливый тон | домик на SVG — не понравился, заменён Zephyr |
| `/spn-13500/` | — | идея про «сеть → ровные 220 В» | осциллограф на canvas, придуман для проекта |
| `/exegate-15kvt/` | — | «разбор по слоям» → метки на фото | метки с подсказками, придумано для проекта |
| `/` главная | [21st.dev — ATC Shader](https://21st.dev/@xordev/components/atc-shader) (XorDev) | идея «полёта сквозь огни» как WebGL-фона | собственный GLSL-шейдер (летящие светящиеся лучи) |
| `/` главная | [UIverse](https://uiverse.io/elements) | кнопка с бликом, карточки с бегущей цветной рамкой, стекло | собственный CSS (`@property --ang`, conic-gradient) |

Исходный код ATC Shader и шаблонов не использовался; подписи в коде, где упомянуты референсы, означают только вдохновение.

## 4. Инструменты и сервисы
- **Python 3.13**: Pillow, NumPy, SciPy (вырезание, оптимизация), rembg/onnxruntime (нейросетевое вырезание), paramiko (SFTP).
- **Хостинг:** Sprinthost (Apache + PHP). **Домен:** oasis.com.ru.
- **Яндекс.Метрика** (счётчик 113489938), **Яндекс Директ**, **Telegram Bot API**, **MAX** (кнопка в карточке заявки).
- **Шрифты Google Fonts:** Manrope (главная, Zephyr), Outfit (Beacon), Inter (Cinnabar), DM Sans (Zephyr). Для остальных — системные.
- **Canva** — генерация картинки дома. **Claude Code** — разработка и написание всей кодовой базы.
- Помощники для прототипирования: three.js (r128, cdnjs) использовался в отвергнутой версии дома, в итоговый сайт не входит.

## 5. Как использовать референсы дальше
Если захочется нового стиля: пришлите скриншот первого экрана и 2–3 блоков (как делали с Beacon, Cinnabar, Zephyr) — этого достаточно.
Код платных шаблонов добывать не нужно и нельзя.
