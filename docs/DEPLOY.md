# Выкладка и настройка

## 1. Сборка
```bash
pip install -r requirements.txt
python make_all.py          # site/ + dist/oasis-site.zip
```
Если менялись исходные фото в `assets/` — сначала `python catalog.py` (вырезание нейросетью, скачает модель u2net ≈176 МБ при первом запуске),
для дома — `python house_matte.py`. Готовые фото уже лежат в `site/img/`.

## 2. Выкладка на хостинг (Sprinthost)
Скрипт `deploy.py` загружает `site/` по SFTP и сверяет контрольные суммы. Пароль — только через переменные окружения:

```bash
set SFTP_HOST=141.8.192.36
set SFTP_USER=a0296626
set SFTP_PASS=********            # не храните в файлах и не коммитьте
set SFTP_BASE=/home/a0296626/domains/oasis.com.ru/public_html
python deploy.py
```
Нюансы хостинга:
- **FTP не использовать:** на этом сервере запись по FTP даёт ложные `451`; рабочий путь — SFTP/SSH.
- SSH иногда отвечает не сразу (нагрузка на сервер) — скрипт повторяет попытки.
- На аккаунте лежат чужие сайты (`~/domains/*`) — трогать только `oasis.com.ru`.
- Для DNS нужна A-запись `oasis.com.ru → 141.8.192.36`.
- Проверять сайт командой `curl --noproxy '*' …`: локальный VPN/прокси может давать ложные 503 и пустые ответы.

## 3. Заявки в Telegram
1. Создайте бота в @BotFather, добавьте его в группу, узнайте ID группы (`getUpdates` или @getmyid_bot).
2. На сервере рядом с `send.php` создайте `config.php` по образцу `server/config.sample.php`:
   ```php
   <?php return ['tg_token' => '…', 'tg_chat_id' => '-100…', 'email' => ''];
   ```
   `config.php` закрыт `.htaccess` (403) и **не коммитится**.
3. Проверка: форма на любой странице → в группу приходит карточка заявки (имя, телефон с кнопками MAX/Telegram, страница, источник `utm`/`yclid`, хэштеги).

Если Telegram отвергнет разметку, `send.php` отправит заявку простым текстом — заявка не теряется. Антиспам: скрытое поле-ловушка и лимит «1 заявка в 20 секунд с адреса».

## 4. Яндекс.Метрика (счётчик 113489938)
Код счётчика встроен в каждую страницу (Вебвизор, карта кликов, отслеживание ссылок). Цели нужно создать в кабинете как «JavaScript-событие»:

| Идентификатор | Когда срабатывает |
|---|---|
| `call` | клик по телефону |
| `tg` | клик по кнопке Telegram |
| `form` | успешная отправка формы заявки |

## 5. Яндекс Директ
- Включить автоматическую разметку ссылок (`yclid`).
- Ссылки объявлений: `https://oasis.com.ru/<страница>/?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_term={keyword}`.
- Метки попадают в карточку заявки в Telegram.
- Соответствие запросов и страниц — в таблице в `README.md`.

## 6. Что правится и где
| Нужно изменить | Файл |
|---|---|
| список моделей, цены, характеристики | `catalog.py` (`STOCK`) |
| телефон, часы, ИП, FAQ, шаги заказа | `build.py` |
| тексты и разметка страницы | `build_<страница>.py` |
| интерактив (калькулятор, шкала, метки) | `widgets.py` |
| ссылка Telegram, номер Метрики | `TG_URL` и `YM_ID` в `build.py`, `build_wow.py`, `build_beacon.py`, `build_cinnabar.py`, `build_zephyr.py`, `build_home.py` |

После правок: `python make_all.py` → `python deploy.py`.
