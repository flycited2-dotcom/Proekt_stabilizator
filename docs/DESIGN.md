# Дизайн и технические решения

## Принципы
- Каждая страница — один самодостаточный `index.html` (CSS и JS внутри, внешние только шрифты Google). Без сборщиков и фреймворков.
- Mobile-first: основной трафик Директа — телефоны. Закреплённая нижняя панель «Позвонить / Telegram» (до 820 px).
- Заголовок H1 повторяет запрос объявления, цена видна на первом экране, телефон и Telegram — в каждой секции.
- Контент только из проверенных данных: ничего не выдумываем (рейтинги, отзывы, «в наличии» не пишем).

## Блоки-«лего» (`widgets.py`, `fx.py`)
- `pf()` — вырезанное фото: парит, наклоняется за курсором, свечение и тень в цвет страницы, увеличение по клику (лайтбокс).
- `anatomy()` — липкая секция, где слои-ракурсы выходят вперёд при прокрутке (используется только на `/spn-13500/`).
- `hotspots()`, `voltage_picker()`, `calculator()`, `series_tabs()` — механики страниц (список выше).
- Цвета интерактива берутся из CSS-переменных страницы: `--pf-glow`, `--pf-rim`, `--pf-accent`.

## Шейдер главной (`build_home.py`)
Фрагментный GLSL на `<canvas>`: 6 слоёв сетки «огней», которые летят от центра к краям (зум), у каждого — хвост вдоль направления движения,
палитра тёплый/голубой/зелёный, виньетка-«тоннель» в центре. Параллакс по мыши; на телефоне камера покачивается сама; прокрутка ускоряет поток.
Разрешение рендера 0,5–0,62 от экрана — нагрузка на встроенные видеокарты невелика. Если WebGL недоступен — остаётся тёмный градиент.
Расчёт поля идёт по `min(R.y, R.x·0.56)`, чтобы на портретных экранах поле было таким же плотным, как на десктопе.

## Правила, которые сэкономят время
1. **Высота картинок — только в `px`/`vh`.** В процентах внутри `grid` картинка растягивается и закрывает соседний текст.
2. **Цены и «15 000 ВА» — с неразрывными пробелами.** `make_all.py → nbsp()` делает это на этапе сборки.
3. **На узких экранах** скрывать «· Симферополь» в шапке, иначе номер обрезается (≤400/520 px).
4. **Таблицы на 320 px:** `table-layout:fixed`, значения переносятся, подписи — нет.
5. **Проверка перед выкладкой:** страницы в `iframe` шириной 320/360/375/390/414 и 1280/1920 → выход за экран (`scrollWidth > clientWidth`) и перекрытие фото с текстом.
6. **Вырезание товара:** белый корпус на белом фоне алгоритмом не вырезать — только нейросеть (rembg/u2net). Листву — `house_matte.py`.
7. **Кэш:** HTML на сервере не кэшируется (`.htaccess`, `max-age=0`), в проверках добавляйте `?v=…`.

## SEO и аналитика
`canonical`, Open Graph, `sitemap.xml`, `robots.txt`; `noindex` снят со всех рабочих страниц. Метрика: Вебвизор, карта кликов, цели `call` / `tg` / `form`.
