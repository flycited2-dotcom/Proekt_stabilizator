# 5 лендингов для Яндекс.Директ: стабилизаторы напряжения

## Цель
Продажа стабилизаторов в Симферополе и по Крыму. 5 страниц под 5 поисковых запросов Директа. Каждая страница в своём стиле, чтобы выбрать лучший и при необходимости переверстать.

## Бизнес-данные
- Регион: Симферополь, весь Крым, новые территории.
- Телефон: +7 978 579-29-95 (звонок). Telegram — добавим позже (пока заглушка `TG_LINK`).
- Режим работы: 7:00–22:00.
- Доставка: по Крыму и на новые территории через транспортные компании. Установку не делаем.
- Домен: oasis.com.ru.

## Общая структура страницы
1. Первый экран: H1 под запрос + «в Симферополе», фото, цена, кнопки «Позвонить» и «Написать в Telegram».
2. Преимущества (3–4 пункта).
3. Таблица характеристик.
4. Для чего подходит (дом, насос, котёл, мощность).
5. Как заказать (3 шага).
6. Доставка по Крыму и на новые территории.
7. FAQ.
8. Повторный призыв к заявке.
9. Подвал: режим работы, «установку не выполняем».
- Мобильная версия: закреплённая нижняя кнопка звонка.
- Яндекс.Метрика: цели на клик по телефону, клик по Telegram, отправку формы (счётчик `YM_ID` — заглушка).

## Техника
- Один самодостаточный `index.html` на страницу (вшитые CSS, без сборки и фреймворков), в папке с именем страницы. Быстрая загрузка, простой деплой.
- Mobile-first, шрифты системные или один Google Fonts.
- Данные, которые нужно подставить позже, помечены заглушками: цены, наличие, фото, Telegram, ID Метрики, механизм отправки формы.

## Принципы контента
- Характеристики моделей берём из открытых источников, неподтверждённое помечаем заглушкой. Ничего не выдумываем.
- Заголовок и текст страницы совпадают с запросом объявления.

## Вне объёма
Бэкенд, корзина, оплата онлайн, монтаж, настройка Директа.

## Открытые вопросы
- Механизм формы заявки (пока кнопки звонка и Telegram, форма без бэкенда).
- Цены, наличие, фото.
