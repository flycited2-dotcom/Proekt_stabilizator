# Лендинги стабилизаторов — план реализации

**Spec:** docs/superpowers/specs/2026-10-04-stabilizer-landings-design.md

**Подход:** генератор `build.py` собирает 5 самодостаточных `index.html` из общего шаблона, общего контента-структуры и пяти тем (CSS + вариант раскладки). Выход: `site/<папка>/index.html`.

## Global Constraints
- Телефон +7 978 579-29-95, режим 7:00–22:00, Симферополь/Крым, установку не делаем.
- Без внешних зависимостей, кроме системных шрифтов; один HTML-файл на страницу.
- Telegram и Метрика включаются одной настройкой в начале файла (`TG_URL`, `YM_ID`); пока пусты — кнопка Telegram скрыта, счётчик не грузится.
- Цены не выдумываем: «уточняйте при звонке».

## Задачи
1. `build.py`: шаблон + контент 5 страниц + 5 тем.
2. Запуск, проверка: 5 файлов, валидность разметки, отсутствие незаменённых плейсхолдеров.
3. Скриншоты на мобильном и десктопе, правки вёрстки.
4. `site/index.html` — навигация по 5 вариантам для сравнения (не для публикации).
